# 05 · 术语表与风险

> 版本：v1.0 ｜ 面向：用户（不需要懂编程）

**这份文件是干什么的？**

它是你这套文档里的**字典 + 保险单**，一共四样东西：

1. **术语表**：看到不懂的词，来这里查。每条都是人话，不抄技术文档。
2. **各阶段常见坑汇总**：把 12 个阶段里容易出的毛病一次性列全。**出了问题先来这里翻**，多半能自己解决。
3. **风险与应对**：技术风险、需求风险、成本风险、隐私风险——提前把「可能出什么岔子、出了怎么办」写清楚。
4. **常见问题 FAQ**：26 条「完全不懂电脑的人」会问的问题，答案都能落地。

**你什么时候需要翻这份文件？** 两个时候：**看不懂某个词的时候**，和**软件出毛病的时候**。平时不用通读。

## 一、术语表（大白话版）

> 📖 用法：按 Ctrl+F 搜你想查的词。每条一句话，不绕弯子。

### 1.1 原大纲术语表（完整保留）

| 术语 | 大白话解释 |
|---|---|
| **API** | 别人家服务器开的「点餐窗口」。你按格式递过去问题，它回你答案 |
| **API Key** | 点餐的会员卡号。代表「这顿饭记你账上」，泄露了别人能花你的钱 |
| **编译** | 把人能看懂的代码，翻译成电脑能执行的机器指令 |
| **exe** | Windows 上的可执行程序文件，双击就能运行 |
| **SDK** | 工具箱。装一次，以后写这类程序都能用 |
| **运行时 / Runtime** | 发动机。程序跑起来必须有的底层支持 |
| **框架 / Framework** | 别人写好的半成品，你在此基础上继续搭 |
| **OCR** | 光学字符识别。把图片里的文字「认」出来变成可以复制的文字 |
| **钩子 / Hook** | 向系统申请「把全系统的鼠标键盘动作告诉我一份」的权限 |
| **剪贴板** | 复制粘贴用的那块临时内存（Ctrl+C 存进去，Ctrl+V 取出来） |
| **剪贴板污染** | 软件偷偷改了你剪贴板里的内容，把你原来复制的东西弄丢了 |
| **悬浮窗** | 浮在其他窗口上面的小窗口 |
| **鼠标穿透** | 鼠标点这个窗口，等于点在它下面的东西上（窗口「透明」了） |
| **DPI / 缩放** | 屏幕显示的放大比例。150% 缩放时，界面元素看起来更大，但坐标要换算 |
| **多显示器** | 接了不止一个屏幕 |
| **单文件发布** | 把程序和它需要的一切打包成一个 exe 文件 |
| **自包含 / Self-contained** | exe 里自带运行时，别人电脑不用装任何东西 |
| **框架依赖 / Framework-dependent** | exe 很小，但别人电脑要先装运行时 |
| **裁剪 / Trim** | 打包时把用不到的代码删掉，减小体积（WPF 不支持） |
| **ReadyToRun** | 提前编译好一部分代码，让启动更快 |
| **降级 / Fallback** | 主方案不行了，自动用备用方案 |
| **兜底** | 最后一层保障，保证「再差也能用」 |
| **缓存** | 把结果先存起来，下次同样的问题直接给答案，不用再问一遍 |
| **接口 / Interface** | 一个「插座标准」。只要按这个标准做，就能插上来用 |
| **插件** | 按接口标准做的独立小模块，能插进主程序里 |
| **降级状态机** | 记录「我现在用的是主引擎还是备用引擎」的状态，以及什么时候该切换 |
| **热更新** | 改了设置不用重启软件，立即生效 |
| **防抖** | 连续快速触发时，只执行最后一次（比如拖动滑块时不要疯狂保存） |
| **内存泄漏** | 程序用过的内存没释放，越用越卡，最后崩掉 |
| **回归测试** | 改了新功能后，把老功能再测一遍，确保没改坏 |
| **里程碑** | 一个重要的阶段性成果（本项目的里程碑是阶段 5 的「核心功能闭环」） |
| **MVP** | 最小可用版本。功能最少但能用的版本 |

### 1.2 补充术语（原表里没有，但正文里一定会遇到）

| 术语 | 大白话解释 |
|---|---|
| **WPF** | 微软做 Windows 桌面界面的新一代工具。它最擅长做「半透明、圆角、不规则形状」的窗口——本软件的悬浮窗和覆盖原文就靠它。代价是要学一门叫 XAML 的界面描述语言，头两天有点懵 |
| **WinForms** | 微软做 Windows 桌面的老一代工具。上手最简单，拖拖控件就能出界面，教程最多；但要做半透明、圆角、动画就很别扭。用它做「覆盖原文」那一步会很痛苦 |
| **NuGet** | 写 C# 程序时的「应用商店」。别人写好的现成功能（比如鼠标钩子库），一条命令就能下载来用，不用自己从零写 |
| **Git** | 给代码存档的工具。每改完一次就存一个「存档点」，随时能退回上一步。改崩了不用重头再来，不联网也能用 |
| **GitHub** | 把代码存档放到网上的网站，相当于代码的云备份，换电脑也能接着做。国内访问有时慢，要注册账号 |
| **SQLite** | 一个小型数据库。整份数据就存在一个文件里，存几十万条历史记录也不卡。本软件用它来存你的翻译历史 |
| **JSON** | 一种用记事本就能打开看懂的文本格式，用来存配置和记录。本软件的配置文件就是 JSON，改坏了软件会自动恢复默认值 |
| **DPAPI** | Windows 自带的加密功能。用它加密的东西**只有你这台电脑的这个账号**能解开，拷到别的电脑上就是乱码——所以你的 API Key 换电脑要重新填（这是好事） |
| **单实例** | 同一个软件只允许开一个。你连着双击两次，也不会冒出两个托盘图标、两个窗口 |
| **托盘** | 屏幕右下角时钟旁边那一小片区域。软件「躲」在那里，不占你的任务栏，也不占屏幕 |
| **Topmost 置顶** | 让窗口永远浮在别的窗口上面，不会被别的窗口挡住——悬浮窗必须这样，不然一切窗口就被盖住了 |
| **DPI 感知** | 程序主动告诉 Windows「我知道屏幕被放大过」。这样在 125% / 150% 缩放下，框选的位置才不会偏、截图才不会截错地方 |
| **调试** | 软件出毛病时，一边让它跑一边查看内部情况，把问题找出来的过程。你不用会调试，但会经常听到这个词 |
| **日志** | 软件自己记的「流水账」文件：什么时候干了什么、哪里出了错，都写在里面。出问题时，把日志发给 AI，它就能查到病因 |
| **进程** | 一个正在运行的程序。按 `Ctrl+Shift+Esc` 打开任务管理器，里面一行就是一个进程。软件「关不干净」时，就要去那里找 |
| **内存** | 电脑里临时放东西的地方。程序开着就占用，关掉就释放。「内存泄漏」就是只占不放，越用越卡，最后崩掉 |
| **WPF 的 XAML** | WPF 里用来描述「界面长什么样」的语言。像写网页一样写窗口布局——这块是给 AI 写的，你只需要知道「它决定窗口长什么样」就行 |
| **OCR 语言包** | Windows 自带的「认字字典」。装了中文包才认得中文，装了英文包才认得英文。没装就会出现「不支持的语言」这个报错，按《03 · 制作流程》里的图文步骤装一次就好 |
| **二进制文件** | 给电脑看的文件（比如 exe、数据库文件）。用记事本打开是一堆乱码。能用记事本看懂的就叫文本文件 |
| **版本号语义** | 版本号 `1.2.3` 三位数字的含义规则：第一位变了是「大改，可能不兼容旧配置」；第二位变了是「加了新功能」；第三位变了是「只修了毛病」。看到 `v1.0` 就知道是第一个能用的正式版本 |

## 二、各阶段常见坑汇总

> ⚠️ **怎么用这一节**：软件出毛病了，先按 `Ctrl+F` 搜症状（比如「没反应」「图标不见了」），找到对应的那一行，照着「怎么办」做。**自己搞不定就把日志和截图发给 AI**，别硬扛。

### 阶段 0 的坑（开工准备）

| 坑 | 症状 | 怎么办 |
|---|---|---|
| 只装了「运行时」，没装「工具箱」（SDK） | 在黑窗口里敲 `dotnet --version` 报错，或者显示的版本不对 | 回下载页面重新下，**认准文件名里有 `SDK` 三个字母的那个**（见术语表：SDK、运行时） |
| 安装开发工具时勾了太多组件 | 装了半小时还没完，硬盘被吃掉一大块 | 只勾「.NET 桌面开发」这一项，其他全部不勾 |
| 公司电脑没有管理员权限 | 装到一半弹出「需要管理员权限」 | 找公司 IT 要权限；或者改成「便携安装」（不需要管理员权限的装法） |
| 杀毒软件拦截安装程序 | 下载好的安装包被删掉、打不开 | 临时关掉杀软，装完再把杀软打开 |

### 阶段 1 的坑（最小骨架）

| 坑 | 症状 | 怎么办 |
|---|---|---|
| 托盘图标不显示 | 屏幕右下角找不到软件的图标 | 先点托盘区那个向上的小箭头「∧」，把隐藏的图标展开；还是没有，就是图标文件路径写错了，让 AI 查 |
| 双击没反应 | 双击了，但什么都没发生 | 多半是「只允许开一个」（单实例）的逻辑写错了：去任务管理器里找找有没有一个藏着的旧进程，结束掉再试 |
| 杀毒软件报毒 | 刚做出来的 exe 就被删掉了 | 这是常见现象，先加白名单（见阶段 9 的决策 9-4）；说明书里会教你怎么加 |
| 窗口关了但程序还在 | 窗口不见了，任务管理器里还能看到它 | 这是界面的默认行为（关窗口 ≠ 退出程序），要让 AI 显式写「关掉就退出」的逻辑 |

### 阶段 2 的坑（组合键 + 拖拽监听）

| 坑 | 症状 | 怎么办 |
|---|---|---|
| 系统把「钩子」摘掉了（见术语表：钩子） | 刚打开能用，用一会儿就失灵了 | 钩子收到鼠标动作时必须**立刻返回**，不能在里面干重活；要让它把活丢给主线程去做 |
| 高 DPI 下坐标错位（见术语表：DPI 感知） | 画出来的框和你的鼠标对不上 | 程序要在配置文件里声明「我知道屏幕被放大过」（PerMonitorV2），让 AI 检查这一项 |
| 遮罩窗挡住了鼠标 | 框选的时候鼠标不动了 | 遮罩窗要设成「鼠标穿透」，让鼠标动作穿过去（见术语表：鼠标穿透） |
| 在全屏游戏里失灵 | 全屏游戏里框选没反应 | 这是正常现象——独占全屏的游戏本来就抓不到。把游戏改成「无边框窗口」模式就好了 |
| 以管理员身份运行的软件抓不到 | 在任务管理器这类程序里框选没反应 | 这是 Windows 的权限隔离，本软件也要以管理员身份运行才行（阶段 8 会提供「以管理员重启」按钮） |

### 阶段 3 的坑（取词 / 识别文字）

| 坑 | 症状 | 怎么办 |
|---|---|---|
| 系统报「不支持的语言」 | 一识别就报错 | 系统没装「认字字典」（OCR 语言包，见术语表）。按《03 · 制作流程》里那几步把中文、英文的「光学字符识别」各装一次 |
| 拿到的是上一次复制的内容 | 总是慢一拍，翻出来的是旧东西 | 发送复制命令之前要先清空剪贴板，或者用「序号比对」的办法判断剪贴板到底变没变 |
| 剪贴板被别的软件占着 | 报「剪贴板被锁定」 | 加自动重试：隔 50 毫秒重试一次，最多试 3 次 |
| 识别结果全是乱码 | 认出来一堆乱七八糟的符号 | 多半是源语言设错了；也可能是框选区域里背景太多、字太少，换个框试试 |
| 多显示器下截图错位 | 截出来的图不是框住的那块 | 还是缩放换算的问题，检查程序的 DPI 设置（见术语表：DPI 感知） |
| 识别速度慢 | 每翻一次要等 2 秒 | 多半是每次都在重新启动识别引擎。应该启动一次、一直复用——让 AI 查这一条 |

### 阶段 4 的坑（翻译内核）

| 坑 | 症状 | 怎么办 |
|---|---|---|
| 译文里带废话 | 输出「好的，以下是翻译结果：xxx」 | 优化给模型的指令，明确要求「只输出译文，不要任何解释」 |
| 翻译模型爱加戏 | 自己补充了原文里没有的内容 | 指令里加一句「严格按原文翻译，不增不减」 |
| API Key 写死在代码里 | 代码文件里能直接搜到 `sk-xxxx` | 必须从配置文件里读；提交代码存档（Git）之前检查一遍 |
| 网络慢时没处理超时 | 网络一不好，界面就卡死 | 所有联网请求都要设超时（建议 10 秒）和「取消」机制 |
| 免费接口被限流 | 连续翻译时报 429 错误 | 加请求间隔（比如 200 毫秒一次）；或者直接降级到下一个通道 |
| 中文被翻成中文 | 明明是中文，结果还是中文 | 语言自动判断的阈值要调，判断中文字符占比的算法要准 |

### 阶段 5 的坑（悬浮窗）

| 坑 | 症状 | 怎么办 |
|---|---|---|
| 窗口跑到屏幕外面去了 | 在屏幕右边缘框选，看不到译文 | 定位要按「可用工作区」算，不能按「整块屏幕」算——要扣掉底下任务栏占的那一条 |
| 窗口抢焦点 | 弹窗之后原来那个软件失去焦点，打字的光标跳走了 | 设 `ShowActivated = false`，用「显示」而不是「激活」的方式把窗口弹出来 |
| 窗口一闪就不见了 | 自己点自己，被误判成「失去焦点」 | 判断「失焦」的时候，要把「点到自己的窗口上」这种情况排除掉 |
| 复制按钮点不动 | 点下去没反应 | 多半是窗口被设成了「鼠标穿透」，把这一项改回来（见术语表：鼠标穿透） |
| 长文本把窗口撑爆 | 窗口比屏幕还高 | 设一个最大高度（比如屏幕高度的 60%），超出部分让它滚动 |
| 半透明窗口的字发虚 | 字看不清 | 别用全透明，用 95% 不透明度；实在不行就改成纯色背景 |

### 阶段 6 的坑（角落面板 + 历史记录）

| 坑 | 症状 | 怎么办 |
|---|---|---|
| 数据库被锁 | 报「database is locked」 | 每次读写都用独立的连接，用完立刻释放；或者改用连接池 |
| 中文搜不到 | 输入中文搜不出结果 | 中文搜索本身没问题，但要注意大小写和空格；必要时改用全文索引（FTS5） |
| 记录无限长大 | 用几个月后数据库变成几百 MB | 自动清理策略必须**真的跑起来**，要写日志确认它执行了 |
| 导出后是乱码 | 用 Excel 打开导出文件全是乱码 | 导出的表格文件要带 UTF-8 BOM 头（让 Excel 知道这是中文） |
| 时间显示不对 | 显示的时间比实际早/晚几小时 | 存的时候统一存「世界标准时间」，显示的时候再换算成本地时间 |

### 阶段 7 的坑（覆盖原文，最难的一步）

| 坑 | 症状 | 怎么办 |
|---|---|---|
| 覆盖层把鼠标挡住了 | 网页点不动了 | 必须加「鼠标穿透」；加完还要专门测一下「还能不能关掉它」（见术语表：鼠标穿透） |
| 页面滚动了，覆盖层还浮在原地 | 覆盖层和原来的内容错位了 | 最省事的做法：**检测到页面滚动就自动关掉覆盖层**；或者干脆设一个很短的自动消失时间（3 秒） |
| 取背景色时取到了文字的颜色 | 填出来的颜色是灰的，很脏 | 取样时避开中间，只取四条边；或者取「出现次数最多的那个颜色」 |
| 译文跑到框外面去了 | 字溢出了框 | 必须先算好字号再画，不能先画完再看合不合适 |
| 覆盖层不消失 | 屏幕上留了一堆，越来越多 | 加一条限制：**同一时间最多只允许存在 1 个覆盖层** |
| 有残影 | 关掉之后屏幕上还留着一块 | 这是透明窗口的经典毛病，关闭时要先把内容清空，再隐藏窗口 |

### 阶段 8 的坑（设置中心）

| 坑 | 症状 | 怎么办 |
|---|---|---|
| 配置文件读坏了，软件打不开 | 双击没反应 | 读配置的动作要包在「出错就忽略」的保护里，读坏了直接用默认值启动 |
| 快捷键冲突没检测 | 设置好了但按了没反应 | 注册快捷键时要检查系统返回的结果，失败就明确提示「这个键被别的程序占了」 |
| 改了设置非要重启 | 体验很差 | 用「配置变更通知」让各个模块立刻刷新，不用重启 |
| 设置项太多没人看得懂 | 你不敢改 | 每一项都加一句人话说明，默认值旁边标注「推荐」 |
| 保存太频繁 | 拖一下滑块就疯狂写文件 | 加「防抖」：改完停手 500 毫秒之后再保存（见术语表：防抖） |

### 阶段 9 的坑（打包成 exe）

| 坑 | 症状 | 怎么办 |
|---|---|---|
| 提示「缺少 .NET 运行时」 | 别人电脑上打不开 | 打包时忘了勾「自包含」（见术语表：自包含），要在发布命令里加上 `--self-contained true` |
| 单文件解压太慢 | 第一次启动要 10 秒 | 关掉压缩（去掉 `EnableCompressionInSingleFile` 这一项） |
| 图标不生效 | 还是默认的空白图标 | 要在项目文件里用 `<ApplicationIcon>` 引用图标，并且重新生成一次 |
| 配置文件找不到，启动就报错 | 一启动就弹错 | 单文件模式下，程序所在目录会指向一个临时文件夹，要用正确的方法取真实 exe 的路径 |
| 任务栏图标不对 | 任务栏上显示成默认图标 | 要在窗口里显式指定图标属性 |
| 放在中文路径里打不开 | 在中文文件夹里双击没反应 | 检查代码里拼接路径的写法：要用官方提供的路径拼接方法，不能用字符串硬拼 |

### 阶段 10 的坑（升级通道）

| 坑 | 症状 | 怎么办 |
|---|---|---|
| 接口设计得太具体 | 以后加新功能还是要改老代码 | 接口里只写「做什么」，不写「怎么做」；参数用通用类型 |
| 检查更新拖慢启动 | 每次启动要干等 3 秒 | 检查更新必须放到后台去做，不能挡住启动 |
| 检查更新失败，软件就打不开 | 一断网就启动不了 | 所有联网操作都要包「出错就跳过」的保护，失败要静默处理 |
| 版本号比较出错 | 1.10 被当成比 1.9 小 | 版本号要按数字一段一段比，不能当成一串文字比（见术语表：版本号语义） |
| 关掉某个模块，依赖它的功能崩了 | 关掉 OCR 之后，取词整个崩了 | 禁用模块时要检查「谁依赖它」，并且给出明确提示 |

### 阶段 11 的坑（本地离线翻译）

| 坑 | 症状 | 怎么办 |
|---|---|---|
| 模型下载中断 | 下到一半失败，文件损坏了 | 支持断点续传 + 下载完校验文件完整性（MD5），损坏就重下 |
| 模型加载太慢 | 每翻一次都卡 10 秒 | 模型要**常驻内存**，只在第一次翻译时加载一次 |
| 中文分词出错 | 翻译结果是乱码 | 分词器必须和模型配套，这是最容易出错的地方，要重点测 |
| 内存爆掉 | 翻几次之后内存涨到几个 GB | 检查是不是每次都重新加载了一遍模型；加上内存监控 |
| 和杀毒软件冲突 | 下载好的模型文件被删了 | 模型文件要放在用户数据目录（`%APPDATA%`），不能放在系统临时文件夹 |

## 三、技术风险与应对

> 📖 这一节照搬原大纲 5.1，一条没删。「可能性」就是「这事发生的概率大不大」。

| 风险 | 可能性 | 影响 | 应对 |
|---|---|---|---|
| 免费翻译接口失效 | **高** | 兜底通道不可用 | 三通道设计（谷歌 / 必应 / MyMemory），坏一个还有两个；出问题及时更新 |
| Windows OCR 语言包缺失 | 中 | 无法 OCR | 首次启动检测，缺失时给图文引导；或改用 Tesseract |
| 高 DPI 坐标错位 | 中 | 框选位置错误 | 用 PerMonitorV2 DPI 感知；每个阶段都在不同缩放下测试 |
| 杀软误报 | **高** | 用户装不上 | 说明书里给三家杀软的白名单教程；必要时提交申诉 |
| WPF 不支持裁剪 | 高（如果选 WPF） | 打包体积降不下来 | 心里有数就行，150 MB 可以接受 |
| 本地翻译分词出错 | 中 | 离线翻译质量差 | 阶段 11 先做可行性实验，不行就换方案 |
| 覆盖层滚动错位 | **高** | 覆盖原文不可用 | 检测到滚动自动关闭覆盖层（最省事） |

**给不懂技术的你，补三句人话：**

- **「免费接口失效」是必然会发生的**：谷歌、必应这两个免费端点不是官方给个人开发者用的，属于「借用」。哪天不能用了，不是软件坏了，是路被封了。所以我们准备了三条路，坏一条还有两条。
- **「杀软误报」也是必然会遇到的**：任何自己编译出来、没有花钱买证书的 exe，都可能被杀软当成可疑程序。这不是你中病毒了，加白名单就行。
- **这两条高概率风险都不影响主功能**：翻译本身走的是 DeepSeek 官方接口，稳得多。

## 四、需求风险与应对

> 📖 这一节照搬原大纲 5.2。「需求风险」的意思是：**做的过程中，想法变了、或者做不出来了，怎么办。**

| 风险 | 应对 |
|---|---|
| 做到一半想加功能 | 阶段 10 的接口机制保证「加功能不用改老代码」；新需求一律排到 v2.1+ |
| 某个阶段做不出来 | **不许偷偷降级**。必须停下来，给出 2-3 个替代方案让用户重新选 |
| 用户对某个效果不满意 | 每个阶段都有「如何测试」，测试时就要提意见，不要等到最后 |

**给你补一句人话：**

- **「想加功能」很正常，但不许当场加。** 你现在想到的点子，会被记下来排进「以后的版本」，不会打断正在做的这一步。否则做到一半改方向，前面全白做。
- **「做不出来」也不丢人，偷偷糊弄才丢人。** 如果某个效果真做不到，AI 必须当面告诉你「做不到，原因是 X」，然后给你 2-3 个替代方案，**由你重新选**，不许自己拍板。
- **验收时别客气。** 觉得字号小、窗口位置别扭、消失太快——当场提。等到最后再说，改起来就贵了。

## 六、隐私风险

> 📖 这一节照搬原大纲 5.4。同样内容的大白话版本在《01 · 成品说明》第七节，两边是一致的。

## 七、常见问题 FAQ

> 🤔 下面 26 条，全是「完全不懂电脑的人」会问的。答案都能落地——照着做就行。

### 1. 我完全不懂编程，这东西我真能用起来吗？

能。**你全程只需要做三件事：选、试、点头。** 选方案（每个决策点给 3 个选项让你挑）、试效果（照着「如何测试」清单点鼠标）、点头验收。代码一行都不用你写。整套流程里唯一要你动手的「技术活」，是装一次开发工具（阶段 0）和申请一次 API Key（阶段 4），两步都有手把手的图文步骤。

### 2. 我不想花钱，能只用免费的吗？

能，但要想清楚代价。软件自带两个免费通道（谷歌、必应），**一分钱不花也能翻**。代价有三：一是免费通道属于「借用」的非官方接口，哪天失效了要接受；二是质量和稳定性不如 DeepSeek；三是没有付费通道兜底时，免费接口一被限流（连续翻译太快会报错），你就得等一会儿。**建议先充 ¥10 试试**，能用很久，实在不想花再切纯免费。

### 3. 为什么要我填 API Key？不填行不行？

API Key 就是「点餐的会员卡号」——不填，付费那家（DeepSeek）不知道这顿饭记谁账上，就没法给你翻译。**不填也能用**：软件会自动只走免费通道。填了的好处是翻译更准、更稳、更快，而且一个月也就几块钱。填的地方在设置中心的「翻译」页，旁边有个「测试连接」按钮，填完点一下就知道对不对。

### 4. 软件会不会偷看我屏幕？

**不会。** 它只在**你按下 `Ctrl+Alt` 并框选**的那一瞬间，才去截取你框住的那一小块区域。你不框选，它什么都不看、什么都不截。它也不会记录你开了什么软件、点了什么、看了什么网站。

### 5. 那它到底会把什么发到网上去？

**只有你框住的那段文字。** 比如你框了一段英文，发出去的就是这段英文，用来换回中文译文。除此之外不发任何东西。如果你连这段文字都不想外传（比如合同、证件），到设置里打开「只用本地翻译」，翻译全部在你自己电脑上算，一个字都不出你的机器。

### 6. 我的翻译记录会被别人看到吗？

记录只存在**你自己电脑的一个文件里**，不上传任何服务器。而且你有三个开关：①「不记录历史」——开了就什么都不留；②一键清空；③自动清理（默认只留 30 天或 5000 条）。数据库文件在哪，说明书里会写明白，你随时可以自己删掉它。

### 7. 我换了台电脑还能用吗？

能，但要搬两样东西。① **软件本身**：把 exe 拷过去就能跑（见第 8 条）。② **设置和 API Key**：因为 Key 是用 Windows 自带功能加密的，**只有原来那台电脑能解开**，换电脑会出现一堆乱码，你需要在新电脑上**重新填一次 Key**——这是安全设计，不是毛病。设置项可以用「导出配置 / 导入配置」一键搬过去。

### 8. 能不能直接拷到 U 盘、拿到别的电脑上用？

能。这就是「单文件 exe」的意思（阶段 9 的成果）：**一个文件、双击就能跑，对方电脑什么都不用装**。注意两点：一是文件比较大（60～160 MB，因为把运行环境也塞进去了），二是第一次启动会慢 1～3 秒（它要先把自己解开），第二次就快了。

### 9. 杀毒软件报警了怎么办？

**十有八九是误报，不是你中毒了。** 自己编译出来、没花钱买签名证书的 exe，被杀软盯上是家常便饭。三招：① 先把软件放进杀软的白名单（说明书里会分 Defender / 360 / 火绒三种，配截图教）；② 实在被删了，就临时关掉杀软再复制一份进去；③ 还不放心，把报警截图发给 AI，走官方误报申诉流程（免费）。**别为了这个花钱买证书**，自己用完全没必要。

### 10. 能不能翻译日语、韩语、法语？

分两种情况。**联网翻译**：能。DeepSeek 和免费通道都支持很多语种，日语、韩语、法语、德语、俄语都不在话下，而且源语言设成「自动」它会自己判断。**离线翻译**：看你下载了哪个语言包，默认只准备中英，想要日语就自己去设置里勾选下载（见第 11 条）。**当前版本的默认方向是「外文 ↔ 中文」**，因为这是绝大多数人的日常需求。

### 11. 断网了还能用吗？

看进度。**阶段 11 做完之前不能**，那时候会明确提示「网络连接失败」，不会假装在翻译。**阶段 11 做完之后能**——前提是你在设置里下载了「离线语言包」（几百 MB，一次性下载，之后不要钱）。离线翻译的质量会比云翻译差一些，长句和口语尤其明显，但意思是对的，总比干瞪眼强。

### 12. 软件会不会拖慢我的电脑？

**正常使用几乎不占资源。** 目标是：空闲时 CPU 占用接近 0%、内存 250 MB 以内——这个水平比开一个浏览器标签页还轻。你会看到它占资源只有三种情况：① 正在识别和翻译的那 1～3 秒；② 下载离线语言包的时候；③ 真的开了离线翻译、正在用 CPU 算的时候（此时可能到 60%，笔记本风扇会响，这是正常的，翻完就降下来）。**如果你发现空闲时 CPU 一直 3% 以上，那是 bug**，告诉 AI 修。

### 13. 按了快捷键没反应，怎么办？

按这个顺序排查：① **软件还开着吗**——看右下角托盘里有没有它的图标，没有就是没启动，双击一下 exe；② **是不是被系统摘钩了**——用久了偶尔会失灵，右键托盘退出、重新打开就好；③ **你框的那个软件是不是「以管理员身份运行」的**——比如任务管理器，权限高的程序抓不到，要么用托盘菜单「以管理员重启」，要么换个窗口试；④ **是不是在全屏游戏里**——独占全屏的游戏抓不到，把游戏改成「无边框窗口」；⑤ 以上都不是，把日志发给 AI（日志在 `翻译软件\tools\日志\`）。

### 14. 框选完了，什么都没出现，怎么回事？

按情况分：① **框太小**——小于 10×10 像素会被当成误触忽略掉，框大一点；② **框里没有文字**——比如框到了图片或者空白，此时应该提示「没有识别到文字」，如果你什么都没看到，那是 bug，告诉 AI；③ **网络断了，识别出来的字翻不了**——应该提示「网络连接失败」；④ **框到了屏幕上会动的内容**——比如视频，覆层可能会立刻自动关闭（这是设计如此，见第 20 条）。

### 15. 翻译出来的字看不清怎么办？

三个办法。① **改背景**：设置中心的「显示」页里，把悬浮窗背景从半透明改成纯色——半透明在花哨的背景上确实容易糊。② **改字号**：同一个页面里能调字号，默认 14，调大到 16～18 更舒服。③ **改不透明度**：调到 95% 或 100%，别用全透明。这些改动**立刻生效，不用重启软件**。

### 16. 译文窗口一直不消失 / 消失太快，能改吗？

都能改。设置中心的「显示」页里有「自动消失秒数」，可以选 3 秒 / 5 秒 / 10 秒 / 30 秒 / 永不消失。**一个贴心细节**：默认 5 秒，但**你把鼠标停在窗口上不动，计时会暂停**——想慢慢看，就把鼠标搁上去；想让它留着，点窗口上的「固定」按钮。如果选「永不」，它会一直待着，直到你点关闭或者框下一段。

### 17. 我框选的时候，会不会影响我正常用电脑？

不会。**只有按住 `Ctrl+Alt` 再拖鼠标才会触发框选**，你平时单击、双击、拖文件、拖滚动条、拖窗口，它全都不管。而且松手之后，它会恢复你的剪贴板内容——不会偷偷把你刚复制的东西弄丢（这条是硬性验收项，必须过）。

### 18. 我框选的区域里面有图片怎么办？

分情况。**图里有字**（比如截图、海报、游戏界面上的文字）：没问题，它会把整块当图片处理，把字「认」出来再翻译。**图里没字**（纯照片、按钮图标）：会明确告诉你「没有识别到文字」，不会崩、也不会瞎编一段出来。**图和字混在一起**：会尽量认能认的字，认不出来的部分可能出错——这时候把框缩小一点、只框文字部分，效果最好。

### 19. 能不能翻译整本的 PDF 或 Word 文档？

**不能，这是明确不做的功能**（见《01 · 成品说明》第四节）。这个软件的定位是「屏幕上看见哪块就翻哪块」，不解析文档结构、不保留排版。想翻一整本，那是另一个软件该干的活。而且说实话：整本翻译出来你也不会逐字读，还是**看哪段框哪段**更实用。

### 20. 我框了一段视频字幕，译文一闪就没了，正常吗？

正常，这是刻意的设计。因为视频一直在动，盖在屏幕上的译文**没法跟着视频一起动**，硬留在那儿只会和画面错位、越看越乱。所以只要检测到画面在变，覆盖层就自动关掉。**看视频的推荐用法**：暂停视频再框，或者干脆用悬浮窗形态（悬浮窗在鼠标旁边，不受画面滚动影响）。

### 21. 为什么有时候同一句话翻出来不一样？

有几种可能。① **换了引擎**：DeepSeek 额度用完时会自动切到免费通道，两家的译法本来就不一样；切回来的时候托盘会弹气泡告诉你。② **上下文不同**：同一句话放在不同段落里，翻译结果可能微调，这是正常的。③ **缓存过期**：短时间内重复翻同一句话会直接给缓存结果（不花钱、秒出），超过 24 小时后重新翻，可能有细微差别。

### 22. 翻译出来的意思明显不对，怎么办？

先试试这三招。① **把框缩小**：框太大容易把无关的字、按钮上的字、页脚的版权声明一起框进去，模型会被带偏。② **看看是不是识别错了**：如果是扫描件、字幕这类靠「认字」的内容，先去 `翻译软件\tools\素材\调试截图\` 看它到底认成了什么——多半是认错了字，不是翻译错了。③ **换引擎重译**：悬浮窗上有个「换引擎重译」按钮，点一下换个通道再翻一次。**都不行就把原文和译文截图发给 AI**，这是模型能力问题，不是软件问题。

### 23. 我不想让别人看到我翻译过什么，怎么彻底删掉？

三步走。① 设置里打开「不记录历史」——从此不再新增记录；② 点「清空历史」——把已有的记录一次删光；③ 关掉软件，去数据库文件所在的文件夹，手动把那个文件删掉（说明书里会写清楚路径），下次启动它会自动重建一个空的。**如果连「翻译内容外传」都不想有**，还要再打开「只用本地翻译」。

### 24. 软件更新了，我的设置会不会丢？

不会。设置和历史记录都存在数据文件里，跟软件本体是分开的。更新方式是「手动下载覆盖」（阶段 10 的推荐做法）：把新的 exe 下下来，替换掉旧的就行，配置一点不动。换电脑时用设置中心里的「导出配置 / 导入配置」，一键搬走。**唯一会「丢」的是 API Key**——因为加密是和电脑绑定的，换机器必须重填（见第 7 条）。

### 25. 怎么知道软件正在运行？

看屏幕右下角的托盘区（时钟旁边）：有它的图标就是在运行。如果看不到，点一下托盘区那个向上的小箭头「∧」，隐藏的图标都在那里。想确认得更彻底：按 `Ctrl+Shift+Esc` 打开任务管理器，在「进程」里搜 `Translator`。**如果两个地方都没有，那就是真没启动**，双击 exe 就行。

### 26. 电脑睡眠唤醒之后就没反应了，怎么办？

这是 Windows 的老毛病：电脑睡一觉，系统会把你申请的「钩子」摘掉（见术语表：钩子）。**最简单的办法**：右键点托盘图标 → 退出 → 重新双击打开。**更好的办法**：这是必须修的问题，告诉 AI，让它监听「系统唤醒」这个信号，唤醒后自动把钩子重新装上。**这一条是硬性验收项**（阶段 12 的 C5 测试：「电脑休眠唤醒后功能正常」），必须过。
