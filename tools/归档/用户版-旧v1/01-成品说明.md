# 01 · 成品说明

> 版本：v1.0 ｜ 面向：用户（不需要懂编程）

**这份文件回答什么问题？**

它只回答一个问题：**「我们要做的这个东西，做出来到底长什么样、能干什么、不能干什么、要花多久、要花多少钱、我的隐私安不安全？」**

你不需要懂任何编程知识，从头看到尾就行。里面每出现一个技术名词，我要么当场用括号解释，要么告诉你「去看《05 · 术语表与风险》」，你随时可以翻过去查。看完这份文件，你心里就有一个清清楚楚的成品样子了——而不是听我说「做一个翻译软件」然后一头雾水。

## 一、一句话说清这个软件是干嘛的

> **按住 `Ctrl + Alt`，用鼠标左键在屏幕上拖出一个方框，把你不认识的外文框进去；手一松，中文译文就出现在你鼠标旁边。**

不用切窗口、不用复制粘贴、不用打开浏览器查。你在看英文网页、PDF 论文、视频字幕、游戏界面的时候，看到哪句不懂，就地框一下就行。

再展开说三句：

- **它不挑软件**：浏览器、PDF 阅读器、Word、记事本、视频播放器、游戏窗口……只要屏幕上能看见外文，就能框。
- **它不挑内容**：网页上能选中的文字它能取；选不中的（扫描件、字幕、图片里的字）它靠「认字」（OCR，见术语表）也能取。
- **它躲在后台**：平时你根本感觉不到它，它就缩在屏幕右下角的小托盘里，等你按快捷键。

## 二、最终效果

### 🖱️ 2.1 平时用起来是什么样

```
┌─────────────────────────────────────────────────────────┐
│  你在看英文网页 / PDF / 视频字幕 / 游戏界面              │
│                                                          │
│  ┌──────────────────────────┐                           │
│  │  This is a sample text.  │  ← 按住 Ctrl+Alt 拖拽框住  │
│  └──────────────────────────┘                           │
│                  ↓ 松手                                   │
│  ┌──────────────────────────┐                           │
│  │  这是一个示例文本。        │  ← 译文直接盖在原文位置    │
│  └──────────────────────────┘                           │
└─────────────────────────────────────────────────────────┘
```

上图是最理想的效果：**译文盖在原文的位置上**，看着就像原文自己变成了中文。这个效果属于「第三批」的增强功能（阶段 7），第一版做出来的是**鼠标旁边弹一个小窗显示译文**，同样好用，只是长得不一样。

### 📖 2.2 使用流程（就四步）

整个软件从头到尾就干四件事。你只需要做第 1 步，后面三步都是它自己完成的：

```
┌──────────────┐       ┌──────────────┐       ┌──────────────┐       ┌──────────────┐
│ (1) 框选     │       │ (2) 识别     │       │ (3) 翻译     │       │ (4) 显示     │
│ 按住 Ctrl+Alt│  ──→  │ 框里的内容   │  ──→  │ 把文字发给   │  ──→  │ 译文显示在   │
│ 拖出方框     │       │ 变成文字     │       │ 翻译服务     │       │ 鼠标旁边     │
└──────────────┘       └──────────────┘       └──────────────┘       └──────────────┘
    约 1 秒              0.05～1.5 秒           0.3～2 秒              瞬间出现
```

四步分别是什么意思：

| 步骤 | 你要做什么 | 软件在背后做什么 | 大概要等多久 |
|---|---|---|---|
| **① 框选** | 按住 `Ctrl + Alt`，用鼠标左键拖出一个方框，松手 | 记住你框住的这块地方在屏幕上的位置 | 你拖多久就多久（约 1 秒） |
| **② 识别** | 什么都不用做 | 先把框里的内容「变成能复制的文字」：能直接选中的地方直接读；选不中的地方（扫描件、字幕、图片）就截图认字（OCR） | 0.05～1.5 秒 |
| **③ 翻译** | 什么都不用做 | 把这段文字发给翻译服务，等它把译文送回来 | 0.3～2 秒 |
| **④ 显示** | 看一眼，需要就点「复制」 | 在你鼠标旁边弹出一个小窗显示译文 | 一瞬间 |

> 💡 全过程 **1～3 秒**，比你自己复制、切浏览器、粘贴、等结果快得多。而且这一切**不打断你正在做的事**——你的网页不会跳走，你的光标不会被抢走。

## 四、明确不做的事

先把丑话说在前面：下面这些事**明确不做**。写上这一节，不是因为我懒，而是因为「什么都想做」的软件最后往往什么都做不好。

原文明确的四条：

- ❌ 不做手机版、不做 Mac 版、不做网页插件
- ❌ 不做文档整篇翻译（PDF/Word 整本翻译是另一个软件）
- ❌ 不做语音翻译、不做同声传译
- ❌ 不做账号系统、不做云同步（第一版不做）

### 🤔 为什么不做的理由

| 不做的事 | 为什么不做的理由 |
|---|---|
| 手机版 / Mac 版 | 我们用的技术（C# / .NET 的 WPF 界面）是 Windows 专属的，做手机版等于**从零再写一个软件**。而且手机上「框选屏幕」这个动作本身就不成立（手指挡住屏幕、系统也不让别的程序读屏）。第一版只服务你自己的 Windows 电脑，最划算 |
| 网页插件 | 网页插件只能翻网页，翻不了 PDF、视频字幕、游戏——等于把软件最大的优势（什么都能框）砍掉了。而且要另外学一套完全不同的技术 |
| 文档整篇翻译（整本 PDF / Word） | 这是另一个量级的产品：要解析文档格式、要保持排版、要处理几百页的分段和上下文，工作量比现在这个软件还大。**我们只做「屏幕上看到的这一块」**，想看哪段框哪段 |
| 语音翻译 / 同声传译 | 要接麦克风、要做语音识别、要处理边说边翻的实时流，是完全不同的一条技术路线。跟「框选屏幕文字」这件事没有半点重合 |
| 账号系统 / 云同步（第一版） | 一旦有账号，就要有服务器、要保证它 24 小时不宕机、要处理别人忘记密码、还要替别人的数据负责。**个人自用软件背这个包袱不值**。历史记录存在你自己电脑上就够了 |
| （隐含的一条）帮你操作别的软件 | 本软件只看、只显示，**绝不替你点按钮、绝不改你的文件**。这是安全底线，不在讨论范围内 |

> 📖 补充说明：如果以后你真想加「翻译整页 PDF」这类功能，阶段 10 的「升级通道」就是为这件事准备的——到时候是「插一块新积木」，不是「把房子拆了重建」。

## 五、做一个要花多久

### 🎯 5.1 先说结论

- 整个过程分成 **12 个阶段**（阶段 1 到阶段 12）。前面还有一步「阶段 0 开工准备」，那一步只是装工具、建文件夹，**不写任何翻译功能**，所以不算在 12 个阶段里。
- **做完阶段 5，你就有一个真正能用的版本了**（托盘常驻 → 框选 → 识别 → 翻译 → 悬浮窗显示 → 复制，闭环打通）。
- 阶段 0 到阶段 5，**大约占整个工作量的一半**。也就是说：**做到一半，你就能天天用了**，不用等到最后。
- 后面 7 个阶段（阶段 6～12）不是「补作业」，是**让它更好用**：加历史记录、加覆盖原文、加设置界面、打包成 exe、留出升级通道、加离线兜底、最后总验收。
- 每个阶段做完，**都要停下来给你验收**。你不点头，就不往下走。这是硬规矩，不许跳步。

> ⚠️ 我不在这份文件里给你报「多少小时、多少天」——那种数字都是拍脑袋编的，编出来只会误导你。我只能告诉你**相对量级**：哪几步轻松、哪几步费劲，看下面的星星就够了。

## 六、要花多少钱

### 💰 6.1 一句话结论

**基本上 ¥0～20 一个月。** 大头是翻译费，而翻译费便宜到可以忽略。

### 📊 6.2 花钱明细

| 花钱的地方 | 大概要花多少 | 说人话 |
|---|---|---|
| DeepSeek 翻译（主力引擎） | **¥5～20 / 月** | 按用量付费，单价极低。日常查查单词、翻翻网页，一个月几块钱；看得特别多也就二十来块。要先充 ¥10 进去试试水 |
| 免费兜底通道（谷歌 / 必应） | **¥0** | 这是备胎：DeepSeek 没额度或抽风的时候自动顶上。不要钱、不用申请。但它是「借用」的免费接口，哪天失效了要接受，不能要求它永久可用 |
| 写代码用的工具 | **¥0** | Visual Studio Community、VS Code 都是免费的，个人用完全够 |
| 杀毒软件误报的「买证书」 | **¥0（不买）**；真要发给很多人用，才考虑 ¥1000-4000/年 | 自己用完全不用买。真被误报了，走免费申诉 + 说明书教人加白名单就够了 |
| 本地离线翻译模型下载 | **¥0** | 只是花点下载流量，模型本身免费。而且是**可选**的，你不想要就不下载 |
| **合计** | **基本上 ¥0～20 / 月** | 一年下来，可能还不如你一杯奶茶贵 |

### 🤔 6.3 三个可能让你多花钱的坑（提前说清）

| 情况 | 会不会多花钱 | 怎么办 |
|---|---|---|
| 忘记自己在用付费引擎，疯狂翻译 | 会，但很慢 | DeepSeek 单价极低，就算一天翻几百次，一个月也就多几块钱 |
| API Key 泄露，被别人拿去用 | **会，而且花的是你的钱** | Key 用 Windows 自带的加密功能（DPAPI，见术语表）存在本地；不写进日志；不发到群里、不传上网。怀疑泄露就立刻去后台删掉重发一个 |
| 额度用完了自己不知道 | 不会多花，但会「变差」 | 软件会自动切到免费通道，还会在托盘弹气泡告诉你「已经切回好的引擎了」，你不会蒙在鼓里 |

## 七、你的隐私怎么办

### 🔒 7.1 先把最要紧的一句话说明白

> **你框选的那块内容，会被发到翻译服务的服务器上去。** 这是所有在线翻译软件的固有事实——不在别人机器上算，就没法翻译。所以你有权知道，也有权选择。

### 📖 7.2 四件你能自己控制的事

| 你的担心 | 软件给你的控制手段 |
|---|---|
| 我不想让屏幕内容传到别人服务器 | **提供「只用本地翻译」选项**（阶段 11 做完后可用）。打开它，翻译全部在你自己电脑上算，一个字都不外传。代价是：需要额外下载离线语言包（几百 MB），翻译质量比云翻译差一些 |
| 我不想留下翻译记录 | **提供「不记录历史」开关**（阶段 6 就有）。打开后，翻完就忘，本地数据库里不留任何新记录 |
| 我翻的东西很敏感，存在硬盘上怕被看到 | **提供一键清空历史**，还有自动清理（比如只留最近 30 天或 5000 条）。数据库文件放在哪，说明书里写清楚，你随时可以自己删 |
| 我的 API Key 会不会被偷 | **API Key 加密存储**（用 Windows 自带的 DPAPI 加密，见术语表）：只有「你这台电脑的这个账号」能解开；拷到别的电脑上就是一堆乱码。软件也绝不在日志里打印 Key |

### 📊 7.3 风险情况和应对（原文照搬，逐条说清）

| 风险 | 说明 | 应对 |
|---|---|---|
| 屏幕内容外传 | 框选的内容会发给翻译 API | 说明书里明确说明；提供「只用本地翻译」选项；提供「不记录历史」开关 |
| API Key 泄露 | Key 泄露会被人花你的钱 | DPAPI 加密存储；不在日志里打印 Key；配置文件不入 Git（不传到代码托管网站） |
| 历史记录含敏感信息 | 数据库里存了你翻译过的东西 | 提供一键清空；提供自动清理；说明数据库位置让用户能自己删 |

### ✅ 7.4 三条你可以放心的

- **它不偷看你屏幕**：软件只在**你按下快捷键并框选**的那一刻，才去截取你框住的那一小块。你不框，它什么都不看。
- **它不上传你的操作**：不上传你开了什么软件、点了什么、看了什么网站。它只上传你框住的那段文字。
- **它不偷偷改你的东西**：不会改你的文件、不会替你点按钮。唯一会「动」你电脑的地方是：你复制译文时它写剪贴板，以及你主动开「开机自启」时它写一条启动项——这两个都在说明书里明写。

> ⚠️ **一句实在话**：如果你要翻的是合同、身份证件、公司机密这类内容，**请打开「只用本地翻译」**。传出去的东西，就没有「撤回」这一说。
