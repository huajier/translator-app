## 你可能担心的三个问题（先答了）

**Q：拆 2842 行的文件，会不会把好好的识别搞坏？**
不会——这次是"**纯搬家**"：一个判断都不改、一个阈值都不动、日志文案一个标点都不改。每搬一步都有两颗"安全扣"（构建 0 错误 0 警告 + 三套探针全过），全部拆完你还要亲自测 28 段。任何一步不对，都能一键退回（每步都有 tag）。

**Q：为什么必须用"部分类"这种拆法？**
因为你们的三套探针是**按"类名+方法名"直接调代码**的（已核实），这种拆法**类名和方法名都不变**，探针一个字不用改、照样能验；拆成"独立类"反而要动探针、风险白翻倍。

**Q：拆完之后，我还能照旧指挥 AI 吗？**
完全一样，只会更顺——以后它改东西"打开对的文件"就行；你要加日语/韩语时，它对你说的话会变成"照形状加一个文件 + 注册一行"，你能听懂的那种。
