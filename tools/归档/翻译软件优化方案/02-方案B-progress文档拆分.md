## 一、为什么拆（现状）

**现在的问题（体检）：**
- 顶部 **约 300 行**是"上一轮状态（已被上面取代）"——一层压一层堆了十几轮，最新状态反而被埋；
- 中间"四、当前成绩账本"又混着**历轮成绩表**（约 290 行）；
- "七、新对话开场白"再重复一遍历史；
- 结果是：**AI 每次开工要读的"规矩 + 待办"只占很少，大半是它早晚要跳过的历史**；而且每轮更新还在往顶上继续堆——**越读越慢，越写越臃肿**。

**拆法总原则（用户拍板的"去重保留"）：**
- 每件事的**完整记录**只留在最权威的一处（`tools\日志\阶段3-验收.md` 已有全部逐轮细节）；
- progress 里只留**一句话结论 + 指路牌**；
- 搬走的内容**一行不删**，进档案文件；原文件在 git 里已留底。
