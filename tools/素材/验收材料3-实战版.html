验收材料 3 · 实战版

这一份专门用来暴露前两份材料照不出的问题：字体不一样、字号不一样、有多行、有中英俄混排。
一共 25 段，每段框一次，按 F → S → M → X → P → C 的顺序做。
P 组请特别注意：那几段上下的字挨得很近， 如果你框的时候切到了上下邻行的笔画，那不是框错了，那正是要测的东西——如实记下来即可。
