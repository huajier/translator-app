**稳定率 84.0%（42/50）。**

### 这对「分数」意味着什么

**跑一轮得到的分数带随机性。** 这次判错的，重跑可能就对；判对的，重跑可能就错。

尤其是 **E21**：稳定时是 `弱点：怕穿透，怕冰`（正确简洁），不稳时会变成 `弱点：穿刺 弱点：冰`（照抄原文结构，明显更差）。同一条目在「对」和「错」之间来回跳。

**所以以后报翻译成绩必须说明跑了几轮。** 单轮分数只能当水位，不能当精确值。这是这次扩语料最大的收获，比 90% 这个数字本身有用。

### 缓存能不能抵消

**部分能。** `TranslationService.cs:71` 有 200 条 LRU 缓存，同一段文字**第二次框**会命中缓存，拿到和第一次一样的译文。
所以**用户实际体验是稳定的** —— 不稳只发生在「第一次遇到这段文字时恰好抽到哪个版本」。

但这不改变测量问题：**我们评的是「第一次会抽到什么」，那本来就有 16% 的概率落在差的那侧。**

## 三、错在哪（5 条）

| id | 类 | 原文 | 译文 | 该怎么译 | 病根 |
|---|---|---|---|---|---|
| E13 | 描述 | Provides reduced visibility **to** enemies… | 提供**对**敌人的可视性降低 | 降低**被**敌人发现的概率 | 修饰方向读反 |
| E16 | 说明 | The menu **where** old character files are presented **under** the "Continue" button | 旧角色文件显示在"继续"按钮下的菜单。 | 用于显示"继续"按钮下旧角色文件的菜单 | 双层从句，语序塌 |
| **E19** | 说明 | **Sortie** using the current setup. | 使用当前设置进行**退出**。 | 使用当前配置**出击**。 | **词义读反**（出击→退出） |
| **E42** | 说明 | …clicking **ORDER** at the bottom right. | 通过点击右下角的"**下单**"确认 | 点右下角的 **ORDER** | UI 按钮被当动词翻 |
| **E39** | 标题 | **Barony** Official Blog — Barony Official Game Website | **男爵**官方博客 — 男爵官方游戏官网 | **Barony** 官方博客 | 游戏名被意译 |

### 5 条错，其实只有 3 类病

1. **修饰关系读反**（E13、E19）—— `reduced visibility to` 方向反了；`Sortie` 当成 `Sortie → exit`。
   这一类**最危险**，因为译文读起来通顺，看不出错。
2. **从句嵌套塌方**（E16）—— 双层从句套不住，缺"的"，读不通。**读者能自己发现**，危害反而小。
3. **专有名词被意译**（E39）—— `Barony` 被当普通名词翻成"男爵"。

**E42 单独一类：UI 按钮词被当动词翻。** `ORDER` 是按钮上印的字，该原样保留，翻成"下单"就变成了动作。
同一个毛病在 E15 上偶尔也出现（6 次里 1 次）。

## 四、对在哪（45 条，说明能力边界）

**这些全部正确，不要再花力气：**

- **术语**：护甲等级、体质分值、远程攻击力、投掷攻击力、元素伤害、光学字符识别、机器翻译
- **型号与引号**：`RX-1轨道炮`、`AR-20L '正义'`、`《Barony》`（E17 里保留对了，E39 里没保留 —— 不一致）
- **数字**：`31 hours 11 mins remaining!` → `剩余31小时11分钟！`、`25%`、`60 FPS`、`2,5 МБ` → `2.5 MB`（俄文小数逗号正确转点）
- **全大写**：`PRIMARY WEAPON`、`WALL BUILDING TOOL`、`ВЫШЕДШИЕ НОВИНКИ`
- **菜单并列**：九项菜单连成一串照样逐项翻对，没被当句子
- **俄文**：6 条全对，含报错、pangram、混拉丁文件名
- **代词回指**：`It is used to read…` 正确译成「它」

**简单句、字段名、物品名、菜单、数字、俄文 —— 都没问题。**
问题**只集中在**：修饰关系、多层从句、UI 按钮词、专有名词。

## 五、语料怎么来的

`tools\素材\翻译评测语料.json`，50 条：

- 全部取自真机取词记录（`tools\日志\历史取词记录\` + `release\v0.4.8.1\logs\`）和 `tools\素材\行真值.json`
- **不是编的句子**
- 少量条目把 OCR 明显错字改回干净版（`oRDER`→`ORDER`、`Chose`→`Choose`），改了什么写在每条 `注` 里。
  本表只量翻译，OCR 的错另由 `L_行` 指标负责
- 全部 ≤400 字，**不触发** `LongTextTranslator` 的切段（`SegmentChars = 400`），避免混入分段因素
- 分布：英 44 / 俄 6；说明 9、段落 9、句子 6、字段 5、物品名 5、标题 4、描述 4、菜单 3、按钮 2、报错 2、数字 1
