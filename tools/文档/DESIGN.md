# DESIGN

界面约定。每条都是用户明确纠正过的，不是审美偏好。改之前先看这里，同一个意见用户不用说第二遍。

## 主窗口

**不放成段说明文字，说明进 tooltip。**

用户原话（2026-11-05）：「乱七八糟的提示删了，ai味太重了」。

改之前主窗口是「三个粗体标题 + 两条横线 + 三大段正文」，等于把 README 渲染进窗口。现在只有控件本身 + 控件后面的问号图标，说明全在 tooltip 里。

**tooltip 只说跟它挂的那件事相关的。**
用户第二次纠正（2026-11-05）：「打开翻译后面问号里面的所有内容都和这个开关不相关」「选择语言后面的问号，里面的内容和翻译语言有任何关系吗」。
把「怎么框选」塞进「翻译语言」的问号里是错的——那种全局操作说明该放主页面正文，不该藏在某个控件的 tooltip 里。

## 图标

**用 Segoe MDL2 Assets 字体图标，不用 emoji，不引图标库。**

用户要「圆圈内问号」，我先提了 U+2753（❓），用户驳回的理由是对的：Windows 上 U+2753 走 Segoe UI Emoji，渲染成**红色彩色 emoji**，和黑白灰界面冲突。

选定：`Segoe MDL2 Assets` 的 **U+E9CE**（圆圈内问号，黑白线条，单色）。
- Windows 10/11 自带，不用打包字体，不占体积
- 是字体不是图片，跟着 `Foreground` 变色，任意缩放不糊

候选码位实测（渲染图存 `tools\临时\glyphs3.png`）：E897 = 无圈问号、**E9CE = 圆圈问号**、EA18 = 盾牌、F167 = 实心 i、EDC6 = 笔。
用之前一定要真渲染出来看，别照文档猜码位。

**鼠标光标保持普通箭头。** 不用 `Cursor="Help"`（箭头旁带黑问号）——用户明确说不要那个图标。

## 文案

**写人话，不写系统词。**

用户纠正：「『译成：』这什么玩意，根本不像人说出来的话，改成『翻译语言：』」。
同义替换要往「用户自己会怎么说」靠，不往「字段名短一点」靠。

## 框选卡片

**滚动条必须跟卡片同色系，不能用 Windows 默认的浅灰。**

用户原话（2026-11-05）：「识别多了后的翻译滚动条很出戏」。

卡片是深色（底 `#F20F172A`、边框 `#FF38BDF8`），系统默认滚动条是浅灰 + 白箭头，深色面板里戳出来一根浅灰，像没改完。
现在用隐式 `ScrollBar` 样式：宽 8、Track `#1E293B`、Thumb `#475569`、悬停/拖动 `#38BDF8`、不做上下箭头按钮。
颜色全部取自卡片里已经存在的色值，不新增颜色。

**代价（已接受）**：没了箭头按钮，端点翻页只能靠滚轮或拖滑块。

## 版本号

**只有一处真源：`src/TranslatorApp/TranslatorApp.csproj` 的 `<Version>` / `<AssemblyVersion>` / `<FileVersion>`。**
窗口标题、任务栏标题都从 `App.WindowTitle`（`App.xaml.cs:77`）取，别在 XAML 里再手写一份。

**发布目录编号跟着程序版本号走**，不用独立的 v1.x / v2.x 编号——用户原话「软件名字还叫翻译软件v0.3.4.3，同步成现在的版本」就是因为两套编号对不上。

## 隐私披露（不许美化掉）

主窗口里那条「框选内容会发到翻译服务」的告知，是**功能的一部分**，不是文案装饰。
删之前想清楚：托盘菜单那句「翻译：把文字发给微软」和首次启动弹窗（`App.xaml.cs:239 EnsureTranslateNotice`）也得同时还在。
三条路都断了就是偷偷外发。
