# 阶段三 S4-D 申请单：小框 3 倍重试（`rapidOcrSmallBoxUpscale`）

> 只读模拟已过门槛（L_行 +2 行、回归 0）。本文是申请单，**不含任何代码改动**。
> 基线：85/121=70.2%、L_行 49/69=71.0%、L_整块 36/52=69.2%、Barony 17/34=50.0%、P95 623.4ms。

## 1. 触发条件（运行时信号，只有 3 个输入）

RapidOCR 在**生产同款输入图**（深字浅底→原图；浅字深底→反色图）上跑完 1x 之后，满足**任一**即用 3x 图重跑一次：

| # | 信号 | 判据 | 命中本语料 |
|---|---|---|---|
| S1 | **结果为空** | `blocks == 0` 或全文 `Trim()` 后为空 | 行-75 |
| S2 | **结果含非 ASCII 字符** | 任一行里存在 `c > 127` 的字符（典型是 行-68 的 `ε`） | 行-68 |

- 两条都是「**块内逐字符**」判定，不是整图统计；S2 必须**逐块**判（首版用整图串判会把含 `'`、`-`、`?` 的图误触，实测触发 12 张、整块 -5.7pp，已废弃）。
- 不引入任何几何/字数/置信度阈值——上一版「高≤40 且 宽<550」无条件 3x 会误伤 行-11（`CHR 1`→`FCHR 1`）和 行-69（`0/7`→`017`），本版结构上不碰它们（两图 1x 都有正常 ASCII 结果，不触发）。

## 3. 耗时（探针实测，非端到端）

| 图 | 1x Detect | 3x Detect | 追加 |
|---|---|---|---|
| 行-68 | 15ms | 19ms | **+19ms** |
| 行-75 | 10ms | 71ms | **+71ms** |

- 只有 2/80 触发，78 张零开销。
- 行-75 正是当前**最慢段**（1.8s，因为它 1x 空后走旧五路回退）。本规则会让它在 3x 一次成功、**跳过整条回退路径**，最慢段预期**大幅下降**而非上升。
- 验收要求：P95 不得升；最慢段记录实测值（预期从 ~1.8s 降到 <800ms）。

## 4. 产品行为

- 开关：`AppSettings.RapidOcrSmallBoxUpscale`，settings.json 键 `rapidOcrSmallBoxUpscale`，**默认 `false`**。
- 开启后：`RapidOcrEngine.TryRecognize` 内部，1x 结果满足 S1/S2 → 对同一输入图放大 3 倍再 `Detect`；3x 结果满足「**非空 且 非 ASCII 字符数不增加**」才采用，否则保留 1x。两条实测都通过：行-68 非 ASCII 1→0、行-75 空→57 字。
- 放大实现：`System.Drawing.Graphics` + `InterpolationMode.HighQualityBicubic`（项目已有 `UpscaleForForeign` 同款），**不新增依赖**。
- 安全阀：放大后边长超 `RapidOcrOptions.MaxSideLen`（默认 2000）时，系数降为 `min(3, 2000/最长边)`。
- 不改识别逻辑、不改阈值、不砸任何一路、不动量具、不改 `TryRecognize` 现有出参签名（只在内部加一次重跑）。

## 5. 验收判据

1. **开关关** → 80/80 输出逐字节相同（sha256 与 `tools\临时\回放-gest-1.txt` 一致）。
2. **开关开** → 全量 ≥87/121、L_行 ≥51/69、L_整块 36/52 不降、Barony 17/34 不降。
3. Z1/Z2/Z3/R1 逐字节不变（Z3 41 字汉字完好）。
4. P95 不升；最慢段记录实测。
5. 3 轮复测，任一轮准确率指标下降即回退。

## 6. 风险（写进结论文档）

1. **行-75 的 `cLICK` 首字母小写**是 3x 副作用。判分 `-eq` 不区分大小写算对，但实机显示是小写 `c`。按你的裁决**不做额外修正**，记账。
2. 探针保真度只有 70/80（「反色 1x」与生产逐图一致数），真实管线里 `TextNormalizer`/`TrimEdgeSymbols`/乱码门会再改一部分文本，**上表 +2 行是上限估计，落地实测可能 ±1 行**。
3. S2「含非 ASCII」是窄判据，只覆盖 行-68 这类混进希腊字母/全角符号的崩坏。行-43（`2 -` 丢 `1`）、行-52（`CZhang` 丢 `-`）都是纯 ASCII 的部分错，本规则救不到——**这类不进本轮**。
4. 若某张中文图 1x 输出含汉字（`c > 127`），会误触 3x。缓解：S2 只对 `!LanguageDetector.IsMostlyChinese(result)` 的块生效（实现时加这一条守卫）。
