### 为什么 v6 全排除
- **tiny**：L_行 30.4%、多出行 36 条 —— 识别头太小，像素字体基本读不出。
- **small**：L_行 69.6%（比 en 差 8.7pp）、**平均 1551ms / P95 2563ms**，直接撞 1.2s 门槛；多出行 17 条。
- **medium**：体积 +125MB，撞 50MB 门槛，不必测。
- v6 多出行集中在裁样边缘（det 短边自适应 736 把边缘噪点也当行），对「单行框选」这个场景是结构性劣势。

## 2. 字典查证（用户 m01592 第 2 条要求）

| 字典 | 行数 | 是否含 `0-9 / % . , - ' ! : ( ) * # @ [ ]` |

| `ppocrv5_latin_dict.txt` | 502 | 全部包含 |
| `ppocrv5_en_dict.txt` | 436 | 全部包含 |
| `ppocrv6_tiny_dict.txt` | 6904 | 全部包含（且含 1 条空格） |
| `ppocrv6_dict.txt` | 18708 | 全部包含（且含 1 条空格） |

结论：**`0/7 → 017` 不是字典缺字符**（换 en 后该例变成整行没认出来，性质变了但也不是缺字符）。
空格丢失同理：en/latin 字典都没有空格条目，模型靠 CTC 空拍隐式分字；这是模型结构问题，换模型不解决。

## 5. 诚实记录：en 带来的新坏点

换模型不是单调变好，有两处 latin 能过、en 反而错得离谱：

| 编号 | 真值 | latin | en |
|---|---|---|---|
| 行-76 | `or rooms. Confirm any changes by clicking ORDER at the` | 对 | `oomsnfrany changs cickig RD`（差 27） |
| 行-83（整块第 2 行） | 同上 | 对 | `orooms. Confirm any changes by clicking oRDER at the`（差 2） |
| 行-83（整块第 1 行） | `CLICK and DRAG with left mouse button to create new walls` | 对 | `CICDA`（差 52） |

原因未定论（怀疑是该区域小字 + 抗锯齿下 en 的识别头对「连笔小写」置信度坍塌）。
按用户规则「不许猜」，先记为**已知回归**，交给第 3 步（字级校验）或后续样本补测判断。

## 7. 改动清单（代码）

| 文件 | 改了什么 |
|---|---|
| `src\Core\Capture\AppSettings.cs` | 新增 `RapidOcrRec`（`en` 默认 / `latin`）；`Load()` 读 `rapidOcrRec`；`Save()` 三个键都写 |
| `src\Core\Capture\RapidOcrEngine.cs` | 按 `RapidOcrRec` 选 rec+dict；**en 文件缺失时自动退回 latin 并记警告**；det/cls 不变；日志打出实际用的模型名 |
| `tools\脚本\装模型.ps1`（新） | 把 en rec+dict 从 `tools\临时\models\en_v5\` 拷进指定 release 目录，带体积/SHA256 校验（`-核对`） |

模型文件**不进 git**（`.gitignore` 已有 `*.onnx` 兜底）。发布时若忘了装模型，引擎会打一条
「英文识别模型缺失，改用包自带 latin 模型」并继续工作，不会崩。

回退方式：`settings.json` 写 `"rapidOcrRec": "latin"`，或整体退回 tag `S3-集成AB-回退`。

## 8. 复现命令

```powershell
# 1) 编译发布
dotnet publish src\TranslatorApp\TranslatorApp.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=false -o release\v0.3.4.3-Rapid-en
# 2) 原生库对齐（publish 会把 Tesseract 换回 5.0.0，必须覆盖成基线的 5.5.3）
Copy-Item release\v0.3.4.3\x64\* release\v0.3.4.3-Rapid-en\x64\ -Force
# 3) 装 en 模型
.\tools\脚本\装模型.ps1 -目标目录 release\v0.3.4.3-Rapid-en -核对
# 4) 开主通道 + 选模型
'{"windowsOnly": false, "rapidOcrPrimary": true, "rapidOcrRec": "en"}' | Set-Content "$env:APPDATA\TranslatorApp\settings.json" -Encoding UTF8
# 5) 跑 121 行
.\tools\脚本\回放-行.ps1 -Exe release\v0.3.4.3-Rapid-en\TranslatorApp.exe
```
