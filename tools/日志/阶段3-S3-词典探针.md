## 七、结论

- 判据「≥6/10」**不成立（5/10）** → 按用户规则，探针不过。
- 「误改 = 0」**成立**（窄规则 0，宽规则 5，说明必须卡死那 4 组形近对）。
- 但按**最终指标**看：+4.3pp（≥+4pp）且零误改——比判据描述的表现更好。
  5/10 的分母里 3 例是型号（`RX-1`、`AR-20L`，两边都不在通用词典）、2 例是
  `attach/attack` 这种两边都是词的。这三类本就不是词典能碰的。
- 换信号源（同图多遍一致性）预检 **1/9**，且 54 个误改入口——同样不过。
- 建议：字级校验这条线按止损规则停。要么接受「只修 a↔o / k↔h 四组形近对」的窄补丁
  （+4.3pp、零误改、开关默认关），要么转「逐行框选引导」（计划 S4）。
