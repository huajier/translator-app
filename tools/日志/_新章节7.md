### 四、🔴 最要紧的一条：护栏挡不住
09:37:44 / 09:53:14 是同一条纯拉丁日志段，**现在是 5/5 全对**：
```
Tesseract：2024-05-01 INFO server listening 2024-05-01 WARN disk usage 92% 2024-05-01 ERROR connection reset   ← 一字不差
Windows  ：2924 一 95 一 91 INFO s e r 、 ve r listening 2924 一 95 一 91 WARN d i s k usage 92 ％ 2924 一 95 一 91 E RROR connectlon r 、 eset   ← 全乱
```
Windows 的字更多（84 > 78）、人话分更高（195 > 163）、**连中文比例都很低**（只有 2 个 `一`，挡不住「没中文」这条护栏），
两边**又都是拉丁文**（挡不住「同文种」这条护栏）——**三条护栏一条都不拦它。**

**而且看清了 Windows 的毛病和 E6 是同一个：它也把词拆开。**
`disk` → `d i s k`、`server` → `s e r 、 ve r`、`2024` → `2924`、`-` → `一`、`92%` → `92 ％`。
**E6 是 Tesseract 把 `editable` 拆成 `edi able`；这里 Windows 把 `disk` 拆成 `d i s k`——同一个病，两个引擎都犯。**

**所以「挑一份更好的」这条路在 E6 上根本走不通：挑谁都可能挑到犯病的那一个。**
