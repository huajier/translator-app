## §3 托盘同步选了方案 b，理由比我的好

`TrayIcon.cs` 新增：

```csharp
_menu.Opening += (_, _) => translateItem.Checked = AppSettings.TranslateEnabled;
```

注释原文（`:96-104`）：
> 为什么不用一个静态字段存 translateItem 再在别处刷新（本来的方案 a）：
> 那等于把「谁是当前勾选态」记在两个地方 —— 字段一份、配置文件一份，
> 什么时候忘了刷新就会不一致。这里每次打开菜单现读配置，
> **配置是唯一真相**，永远同步，也就不需要谁去记得刷新。

**这是对的，而且比我给的选项 a 更懒。** 我上次给 a 排前面是错的——多一个静态字段就多一份要维护的状态。

## §5 两个小瑕（不阻断，可留到下一轮）

### P1-I1 「其他…」清空后不填就走，界面显示空、配置还是旧值

`MainWindow.xaml.cs:144-151` 选中「其他…」时 `SelectedIndex = -1; Text = ""` 并聚焦。
若用户**不输入直接点别处**：`CommitLangFromText` → `CommitLang("")` → `:204` 空串早退 → **配置不变（正确）**，
但**下拉框就那么空着**，用户看不出当前译成什么。

修改建议（一行）：`OnLangLostFocus` 里若 `CommitLangFromText` 之后 `LangBox.Text` 仍为空，
就把 `AppSettings.TranslateTargetLang` 填回框里。

### P1-I2 手填只认语言代码，普通用户不会写 `ja`

现在提示是「直接在下拉框里填语言代码（如 ja、de、xx-YY）」。非技术用户想译成日语，
第一反应是打「日语」两个字 → 存进去 → 请求 `to=日语` → 400。

修改建议（不建校验表，只加一张**中文别名→代码**的小映射，10 条以内）：
`日语→ja`、`日文→ja`、`英文→en`、`英语→en`、`韩语→ko`、`俄语→ru`、`法语→fr`、`德语→de`、`繁体→zh-Hant`。
**命中就换代码，没命中照原样送**——不改变「不做校验表」的决定，只是把最常见的手误接住。
