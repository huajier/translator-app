## 2. P0-C1（硬阻断）：`HttpListener` 在本机起不来，T2 方案要换实现

**实测三路都失败**（探针 `tools\临时\探针-本地监听.ps1`、`-2.ps1`）：

```
HttpListener localhost:5099  => FAIL :: System.PlatformNotSupportedException :: 此平台上不支持该操作
HttpListener 127.0.0.1:5098  => FAIL :: System.PlatformNotSupportedException
TcpListener  127.0.0.1:5097  => OK（含请求-响应往返）
[System.Net.HttpListener]::IsSupported = False
OSVersion = Microsoft Windows NT 10.0.19045.0 / PS 5.1.19041.7291 / CLR 4.0.30319
```

原因不必深挖（HTTP.sys 组件缺或受限），**结论够用：方案 §9.14 和 §7 里「HttpListener + 路由」这个实现方式作废。**

**改成 `System.Net.Sockets.TcpListener` 手写最小 HTTP**（已验证可用，零新依赖，仍是一个 .ps1）：
- 单线程 `AcceptTcpClient` 循环就够（测试工具，不需要并发）。
- 读请求头直到 `\r\n\r\n`，从请求行解析 `GET /translate?api-version=3.0&mode=xxx`。
- 回包必须两件事写对，否则客户端会挂死或报 JSON 解析错：
  1. `Content-Length` 用 **UTF-8 字节数**，不是 `string.Length`（中文译文一定要测这条）；
  2. `Content-Type: application/json; charset=utf-8`。
- 端口写死 5099，被占用就 +1 重试并把**实际端口**打进输出。

## 3. P0-C2：隐私文案在替微软做我们控制不了的承诺

现在两处写着「**发完不留存**」：`App.xaml.cs:246` 的 detail、方案 §5 第 101 行。
这是我们**无法保证**的事——留不留存由微软的条款决定，不由我们决定。一旦哪天被用户发现不是这样，损失的是整个提示的可信度。

**改法（最小）**：删掉「发完不留存」，只陈述我们这边发什么、不发什么：

```
框选到的文字会发到微软翻译服务。只发文字，不发截图、不发窗口标题、不发进程名。
```

我方行为（只发文字）是我们能兑现的；微软侧行为留给微软的条款。若要保留任何关于微软的陈述，必须把官方链接抄进注释（本轮 `web_search` 仍 401 不可用，别凭印象写）。

## 5. P1-C1：本机有 127.0.0.1:7890 的代理，T3 打本地假服务器可能被截走

IE 设置实读：`ProxyEnable=0`、`ProxyServer=127.0.0.1:7890`（开机可能是关的，随时能被打开）。
公司网络（用户 Q4 明确提到）通常也需要代理，所以**不能对微软那一路关代理**。

T3 落 `AzureTranslatorProvider` 时加一条：**endpoint 主机是回环地址时，该 HttpClient 不走代理**（`HttpClientHandler.Proxy = null`，按 endpoint 建一次 HttpClient 即可）。否则代理一开，`http://127.0.0.1:5099` 会被送去 7890，表现为「假服务器一切正常但程序说连不上」，排查半天。

## 6. P1-C2：Q5「等译文到了才开始」必须落成「只调一次 UpdateWith」

用户 Q5 原话：「等译文到了才开始」。
若 T3/T5 接线写成「先 `UpdateWith(result)` 显示原文，译文到了再 `UpdateWith(result, translation)`」，
则 3 秒倒计时从**原文**到手那刻起算（`DebugToastWindow.xaml.cs:438-440` 每次都重启定时器），
译文晚到 2 秒 = 用户只剩 1 秒看译文，正是 Q5 要避免的。

**契约（写进方案 §8，T3/T5 都照这条）**：`RunCaptureAsync` 里翻译跑完才调**一次** `card.UpdateWith(result, translation)`；
翻译失败时也走这同一次调用（translation 带 Failure），不许分两次；翻译期间卡片保持 `PendingCloseDelay`（8 秒）兜底，不能提前关。
