# PaddleOCR issue #18373 (v6 det hallucination, collaborator confirms)
https://github.com/PaddlePaddle/PaddleOCR/issues/18373
User (PaddleOCR 3.7.0): detection model reads handwriting scars as text, then recognition
outputs unrelated text. "即使我设置了识别置信度为0.7，还是无法很好解决这个问题。"
Collaborator Curry-Christopher: "Hi, I've reproduced this issue. The v6 detection model has
some hallucination on handwritten images like this one, and adjusting the thresholds probably
won't fix it for now. I'd recommend using PaddleOCR-VL-1.6 ..."
=> Hallucination happens at DETECTION stage, and rec score 0.7 does not filter it out.
