# tools · 杂物间

> 这个文件夹是**软件的杂物间**。
> 规则只有一条：**凡是不属于「软件本身」的东西，都放这里。**

---

## 各子目录放什么

| 子目录 | 放什么 | 举例 |
|---|---|---|
| `安装包\` | 下载回来的安装程序，装完别删，换电脑还用得上 | `dotnet-sdk-10.0.x-win-x64.exe`、`VisualStudioSetup.exe` |
| `脚本\` | 一次性脚本、发布脚本、生成测试数据的脚本 | `发布.ps1`、`生成测试数据.ps1`、`清理日志.bat` |
| `素材\` | 参考图、测试用的截图、图标草稿 | `测试样本\网页英文.png`、`调试截图\` |
| `日志\` | 调试日志、报错记录、踩坑笔记、决策执行记录 | `框选坐标.log`、`翻译.log`、`决策执行记录.md` |
| `归档\` | 历史版本的大纲、废弃的方案 | `制作大纲-合并原始版-v1.0.md` |

---

## 什么算「软件本身」

这些东西**放 `翻译软件\` 的对应目录，不放这里**：

| 放哪 | 放什么 |
|---|---|
| `src\` | 源代码、项目文件 |
| `docs\` | 成品的说明书、更新日志、常见问题 |
| `release\` | 打包好的 exe |
| `backup\` | 每个阶段开工前的可用版本备份 |
| `assets\` | **会被打进 exe 的**图标、字体 |

> 注意 `assets\` 和 `tools\素材\` 的区别：
> - 会被打进 exe 的图标 → `assets\`
> - 只是拿来参考、测试用的图片 → `tools\素材\`

---

## 三条不许

1. ❌ 不许在 `翻译软件\` 根目录乱建文件（比如随手扔一个 `test.py`、`1.txt`、`新建文本文档.txt`）
2. ❌ 不许把临时脚本放 `src\` 里
3. ❌ 不许把 API Key、密码、账号写进这里的任何文件

---

## 定期清理

`日志\` 和 `素材\调试截图\` 会越攒越多。AI 每完成 3 个阶段应该提醒你清理一次，保留最近 30 天的就够。
